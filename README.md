# Doctors Home Care At Door Step

Website for **Doctors Home Care At Door Step Private Limited** — 24/7 doctor home visit & home healthcare services in Kathmandu Valley.

**Live domain:** [https://doctorshomecare.com.np/](https://doctorshomecare.com.np/)

## Tech stack

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (backend / CMS)
- Deployed on Vercel
