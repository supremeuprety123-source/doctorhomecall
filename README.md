# Doctors Home Care At Door Step

Website for **Doctors Home Care At Door Step Private Limited** — 24/7 doctor home visit & home healthcare services in Kathmandu Valley (Kathmandu, Lalitpur, Bhaktapur).

**Live domain:** [https://doctorshomecare.com.np/](https://doctorshomecare.com.np/)

## Tech stack

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (backend / CMS)
- Deployed on Vercel

## SEO & Google verification

- Google Search Console meta tag in `index.html`:
  `google-site-verification=7ARV7pdctbfrdFkImmwbJ_tPlvICyfwleY7Ur0TZPJY`
- `public/robots.txt` and `public/sitemap.xml`
- Structured data: MedicalBusiness, LocalBusiness, WebSite, FAQPage
- Geo meta tags for Kathmandu / Nepal

### After deploy

1. Open Google Search Console → Verify ownership (HTML tag method)
2. Submit sitemap: `https://doctorshomecare.com.np/sitemap.xml`
3. Request indexing for `/`, `/services`, `/appointment`
